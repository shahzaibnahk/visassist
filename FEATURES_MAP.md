## 🔧 Backend API Structure

### API Endpoints Map
```
VissaAssist API (FastAPI)
├── 📍 /api/applications
│   ├── GET    /              → List all
│   ├── GET    /{id}          → Get one
│   ├── POST   /              → Create
│   ├── PUT    /{id}          → Update
│   └── DELETE /{id}          → Delete
│
├── 📍 /api/countries
│   ├── GET    /              → List all countries
│   ├── GET    /{code}        → Country details
│   └── GET    /{code}/visa-types → Visa options
│
├── 📍 /api/chat
│   ├── POST   /              → Send message
│   └── GET    /history       → Get history
│
├── 📍 /api/admin
│   ├── GET    /stats         → Dashboard stats
│   ├── GET    /users         → All users
│   └── GET    /applications  → All applications
│
└── 📍 /docs                   → Swagger UI
```

## 📦 Technology Stack

```
Frontend
├── React 18          → UI Framework
├── Vite              → Build tool (super fast!)
├── Tailwind CSS      → Styling
├── React Router v6   → Navigation
├── Axios             → API calls
├── Lucide React      → Icons
└── Framer Motion     → Animations

Backend
├── FastAPI           → Python web framework
├── Motor             → Async MongoDB driver
├── Pydantic          → Data validation
├── Uvicorn           → ASGI server
└── Python-Jose       → JWT authentication (ready)
```
